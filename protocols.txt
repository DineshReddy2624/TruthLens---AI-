2. How to Share the Project

When sharing (via ZIP or Git):

Include these files & folders:
truthlens.db (The database containing all your data)
requirements.txt (Complete Python dependencies)
backend/
frontend/
.env.example
setup.bat, start.bat, start.sh
TruthLens_User_and_Admin_Guide.pdf
Do not include (or delete before zipping to save space):
backend/.venv (your friend will generate their own via the setup script)
frontend/node_modules
3. How Your Friend Installs Dependencies (1 Command)
Option A — Automated 1-Click Setup (Windows)

Your friend just needs to double-click:

text
setup.bat

This automatically sets up Python, installs all packages from requirements.txt, installs frontend packages, and configures .env.

Option B — Terminal Commands (Any OS / Windows / Mac / Linux)

Step 1: Install Python dependencies (from project root):

bash
pip install -r requirements.txt

Step 2: Install Frontend dependencies:

bash
cd frontend && npm install && cd ..

(Optional: Copy .env.example to .env if not already present):

bash
cp .env.example .env
4. How to Start the Project
Option A — 1-Click Launchers (Easiest)
On Windows: Double-click start.bat
(This launches both the backend and frontend in separate console windows and automatically opens http://localhost:3000 in their browser).
On macOS / Linux: Run ./start.sh
Option B — Manual Terminal Commands

Open two terminal windows:

Terminal 1 — Backend API:

bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

Terminal 2 — Frontend UI:

bash
cd frontend
npm run dev

Then open your browser to http://localhost:3000.

Option C — Docker (Full Containerization)

If your friend prefers Docker:

bash
docker compose up --build
